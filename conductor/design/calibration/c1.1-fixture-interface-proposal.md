# C1.1 fixture interface proposal

Status: proposed owner 04/21 review input; not a frozen physical schema or runtime API. Synthetic fixtures only. No standard/local-feed conformance or source availability is inferred.

## Decisions to freeze before dispatch

1. Use separate physical trace-event, exclusion and outcome-observation tables, each with exact versioned schema and explicit field/schema metadata. Reuse the accepted C0 logical names and enums; include all three source clocks, knowledge availability, declared precision, lineage and raw source evidence. Do not overload legacy event_log.v1 or Q4 resource_lifecycle.v1.
2. Relative ticks remain required 16-byte little-endian u128 and canonical decimal JSON. For absolute UTC, propose signed i128 little-endian fixed16 plus explicit UTC/ns metadata; never force its full range into Arrow's signed-64 nanosecond timestamp. Bind a reviewed UTC text/range codec separately; source-text parsing and precision remain distinct from storage encoding. Nullable optional clocks stay null. Owners must approve exact nested field layout/nullability and range before fixture generation.
3. A synthetic wide/long profile explicitly maps source fields and event kinds/ranks. Neither shape infers meaning from a field name. Retain stable case/source-event keys and source_order. Duplicate source-event keys reject the dataset under C0; any row-level quarantine or dedup requires a separately reviewed policy and exact accounting oracle. No silent winner by file order.
4. Default source-time policy rejects naive/unknown-zone input. DST fold/gap tests must bind an exact resolver and TZDB revision, or exercise explicitly preclassified ambiguous/nonexistent inputs with that limited claim. An explicit-offset positive fixture must have independently computed UTC and preserve source precision. Do not invent midnight for dates or finer resolution for minute observations.
5. Freeze exact accepted/excluded/censored/missing/unmatched counts and typed reason precedence per fixture. Preserve input conservation and denominator definitions. Eligibility at prediction requires evidenced availability by the cutoff; future/unknown knowledge cannot become a known feature. Observed targets remain distinct from predicted/clamped outcomes.

## Required fixture matrix

| Group | Positive/control | Negative/oracle |
| --- | --- | --- |
| Formats | External Python writes / Rust reads and reverse; exact calibration fields/metadata | Changed role/precision/schema/nullability fails exact schema validation |
| Timestamps | ns/us/ms/s represent one independently computed instant; explicit offset; retained minute precision; full relative tick boundary | Unknown zone, fold/gap, missing occurrence, pre-origin, sub-ns and overflow/range cannot fabricate ticks |
| Shape/order | Equivalent wide/long source with repeated occurrence and equal-time keys; batch/row-group permutations | Duplicate key, missing rank/key and source-order substitution cannot silently reorder or deduplicate |
| Quality | Ordered/open location interval; separately sourced episode-end and later physical departure/boarding | Reversed interval, missing triage denominator, absent endpoint and censored outcome retain reasons/counts |
| Knowledge | Earlier evidenced feature and later retrospective target | Future/unknown availability cannot enter prediction context |
| Source semantics | Role-correct synthetic source-field controls with explicit lineage | meta.lastUpdated is not source-recorded time; MSH-7 is not occurrence; A08 alone is not physical movement; OMOP visit-end without ETL lineage is not observed physical departure |

Synthetic source labels are semantic counterexamples from the accepted project contract, not complete FHIR/HL7/OMOP parsers. Bind separately inspected editions/dictionaries before claiming standard conformance. Raw private identifiers stay outside portable fixtures.

## Integration boundary

Q4 owns its DES/ABM transitions, lifecycle Arrow sidecar and parent pin. C1 may add dedicated fixture/schema assets with exact disjoint claims; it must not edit Q4 telemetry encoders, shared Cargo manifests/locks or scheduling records. The parent coordinator serializes pin/task-catalog/current-state integration. No portable checkpoint, statistical calibration or final MVP acceptance follows from this proposal.
