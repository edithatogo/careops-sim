## Scope and Subsequent Boundaries

Acceptance of Phase C6 concludes the `empirical_calibration_20260925` track and establishes the following boundary commitments:

1. **Synthetic ED Baseline Boundary**: All calibration and validation benchmarks operate on synthetic fixtures informed by open literature and operational queuing dynamics (ATS 1–5 urgency, zone eligibility, diagnostic bay holds, urgent preemption work conservation, bed cleaning cycles, and boarding bay retention). No clinical policy approval, real-hospital patient data, or Cairns Hospital site-specific parameter claims are asserted.
2. **Headless Native Engine Boundary**: The discrete event simulation (DES), agent-based spatial transit (ABM), shadow ledger replay, and calibration runner execute 100% headless in pure native Rust with zero mandatory Python runtime, zero GPU or CUDA requirements, and zero browser/GUI display dependencies (C-07).
3. **Explicit Downstream Handoff Contracts**:
   - **Metal / GPU Acceleration (Track 32)**: Distance reduction contracts and memory layouts (`#[repr(C)]`) are verified with declared tolerance $\epsilon \le 10^{-12}$. Physical Metal GPU device execution remains unverified in headless CI and falls back cleanly to CPU compute.
   - **PDES Multi-Worker Partitioning (Track 34)**: Logical process (LP) partitioning, non-zero lookahead via positive edge transit, and worker completion order invariance (C-06) are verified. Physical cluster deployment remains unverified.
   - **Distributed Telemetry Batching (Track 35)**: Arrow IPC telemetry payload wrapping (`arrow_ipc_payload: Vec<u8>`) and deterministic GVT advancement are verified via software transport emulation.
   - **Visualization & Wasm Parity ([hybrid-model appraisal](../hybrid-model-insights.md))**: Simulation engine is the sole owner of virtual simulation time; render-rate decoupling (0, 30, 60 FPS, frame jitter) preserves 100% bit-for-bit trajectory invariance; UI backpressure never stalls simulation progress; and tick counts are bounded by IEEE 754 safe integers (`MAX_EXACT_TICK = 2^53 - 1`). Physical PixiJS browser rendering remains with front-end owners.
