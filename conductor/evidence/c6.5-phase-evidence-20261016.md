### Criterion C-02: Macro/Micro Fidelity, Spatial Routing & Urgent Interruption

> **Specification**: *Macro produces no transit events; Micro routes deterministically and interrupts/resumes correctly. A zero-transit/no-extra-policy Micro fixture matches Macro task outcomes/draws. Mixed modes obey precedence and boundaries.*

- **Implementation**:
  - `crates/careops-ed/src/domain.rs` & `operational.rs`: Core ED operational state machine modeling patient presentation, ATS 1–5 urgency triage, zone-based staff dispatch, diagnostic holds, preemption, bed cleaning, and boarding.
  - `libs/kairos/crates/kairo-ecs-calibration/src/experimental_c5.rs` & `api_runner.rs`: Dual-fidelity evaluation runners supporting Macro (0 transit) and Micro (explicit graph transit delay) execution.
- **Evidence & Verification**:
  - `test_c61_dynamic_4_urgent_preemption_work_conservation_and_resume` (`crates/careops-ed/tests/c61_ed_fixture_verification.rs`).
  - `test_frozen_parameters_free_running_macro_micro_held_out_evaluation` (`libs/kairos/crates/kairo-ecs-calibration/tests/c62_ed_holdout_evaluation.rs`).
  - Macro execution emits exactly 0 transit ticks and 0 spatial movement events.
  - Micro execution routes agents deterministically along graph paths with integer tick delays.
  - When an urgent arrival (ATS 1/2) preempts an in-flight low-acuity task (ATS 4/5), accrued work ticks are preserved in queue (`work_elapsed_ticks`); preempted patients resume and finish without work loss or duplication.
  - Under zero transit ticks and identical queue policies, Micro matches Macro task completion times, random draw sequences, and queue outcomes bit-for-bit.
  - Policy resolution respects strict hierarchy: `(entity, subsystem)` override > entity override > subsystem default > global default, frozen at task admission.
- **Disposition**: **SATISFIED**.

### Criterion C-04: Deterministic Distribution Metrics & Statistical Assumptions

> **Specification**: *W1/KS analytic/reference fixtures pass; invalid/empty/tied/censored inputs are correctly classified. Precision and inference assumptions are reported.*

- **Implementation**:
  - `libs/kairos/crates/kairo-ecs-calibration/src/metrics.rs`: Deterministic sorted-CDF Wasserstein-1 ($W_1$) and Kolmogorov-Smirnov ($KS\ D$) calculation using exact rational reductions.
  - `libs/kairos/crates/kairo-ecs-calibration/src/sidecar.rs`: Emits metric records joined with input hashes and validity flags.
- **Evidence & Verification**:
  - `test_marginal_vs_joint_conflicts_and_uncertainty_decomposition` (`c62_ed_holdout_evaluation.rs`).
  - Kairos suites `tests/metrics_c41.rs`, `tests/metrics_c42.rs`, `tests/residuals_c42.rs`, and `tests/sidecar_adapter_c43.rs`.
  - Analytic fixtures match exact rational expectations: $A=[0,2], B=[1,3] \implies W_1 = 1.0, KS\ D = 0.5$; identical arrays yield $0.0$; $A=[0,0], B=[1,1] \implies 1.0$.
  - Invalid, empty, or single-point cohorts fail closed or return typed `insufficient-data` / `coverage-warning` statuses rather than misleading zero distances.
  - Default inference omits automatic classical p-values for tied/clustered ED records; documented cluster-bootstrap and precision-cap assumptions are enforced.
  - Joint divergence detection (Report 12 FX-007): identical marginals with reversed dependence yield $W_1 = 0, KS\ D = 0$ but are flagged by multivariate energy distance ($\mathcal{E} \approx 0.5858 > 0.4$).
- **Disposition**: **SATISFIED**.

## 6. Downstream Handoff Contracts and Unverified Boundaries

In accordance with Conductor governance, all software interfaces and contracts are verified, while physical hardware and UI presentation layers outside this track are explicitly demarcated as unverified:

1. **Track 32 (GPU / Metal Compute Acceleration)**:
   - *Verified Software Contract*: Memory layouts (`#[repr(C)]`), zero-copy host-device transfer structs, canonical sorting prior to reduction, and CPU-to-GPU numerical tolerance $\epsilon \le 10^{-12}$.
   - *Explicit Unverified Boundary*: Physical Metal shader compilation and live GPU hardware device execution remain unverified in headless CI; the system falls back to `CpuFallbackCompute` with typed non-configured errors.
2. **Track 34 (PDES Multi-Worker Simulation)**:
   - *Verified Software Contract*: Logical Process (`LpId`) candidate partitioning, positive lookahead via graph transit minimums, and worker completion order invariance (C-06).
   - *Explicit Unverified Boundary*: Multi-node physical network execution and live CMB null-message cluster benchmarks remain unverified.
3. **Track 35 (Distributed Simulation & Transport)**:
   - *Verified Software Contract*: Arrow IPC byte payload serialization (`arrow_ipc_payload: Vec<u8>`), standard schema tagging, and deterministic GVT reduction.
   - *Explicit Unverified Boundary*: Live MPI daemon communication and gRPC remote cluster deployments remain unverified.
4. **Tracks 05/09 & Hybrid-Model Appraisal (Wasm & Visual Renderers)**:
   - *Verified Software Contract*: Simulation engine is the sole owner of virtual simulation time; render-rate decoupling (0, 30, 60 FPS, frame jitter) preserves 100% bit-for-bit trajectory invariance; slow-consumer bounded buffer coalescing prevents UI backpressure stalls; and tick values are bounded by IEEE 754 safe integers (`MAX_EXACT_TICK = 2^53 - 1`).
   - *Explicit Unverified Boundary*: Browser WebAssembly packaging, PixiJS canvas layout, and live browser user interaction remain with frontend owners.
5. **Clinical & Site Parameter Boundary**:
   - *Verified Software Contract*: Synthetic queuing mechanics, ATS urgency dispatch, diagnostic holds, preemption work conservation, and cleaning/boarding states.
   - *Explicit Unverified Boundary*: Real-world clinical validation, real hospital EHR data ingestion, and Cairns Hospital site-specific parameter profiles remain unverified.
