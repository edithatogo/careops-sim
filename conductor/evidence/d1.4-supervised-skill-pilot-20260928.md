# D1.4 supervised skill pilot results

Date: 2026-09-28 (Australia/Brisbane)

## Scope and controls

This receipt records the post-policy synthetic, read-only GPT-6 Luna pilot under
the pre-registered [D1.4 policy](d1.4-evaluation-policy-20260928.md). Each
baseline and skill-assisted response came from a fresh task context (`fork_turns
= none`) at low reasoning effort. The exact case facts and required response
shape were paired within each case. No oracle disposition was included in a
worker prompt. Workers were instructed not to use tools or inspect repository
files; their reports say no tools were used. No actual repository patch, CI run,
clinical data, or implementation was reviewed in these synthetic exercises.

This is context-level separation only. The agents share a host and filesystem;
there is no technical oracle isolation, and this receipt does not claim one.
Expected dispositions below were determined by the coordinator from the
predeclared facts/contract and recorded after each pair completed. These small
convenience samples do not support population error estimates or confidence
bounds.

parallel DET-01 replay is reported above but is not added to the independent

The false-pass denominator is six unique known-bad cases times two arms. The
positive calibration case is the only accepted response in each arm, hence the
bad-among-accepted denominator is one per arm. The reported zero corrections
means no follow-up correction turn was issued in this pilot; it is not an
independent measure of reviewer effort. Output length was not consistently
captured and is not scored. Parallel dispatch covered MSRV, clamp, and the DET-01
repeat; other scored unique cases ran serially. Thus only DET-01 has a direct
same-case serial/parallel scheduling comparison.

## Interpretation and disposition

The determinism skill correctly escalated an explicit mismatch between the
claimed event tie-break and the required contract; the baseline asked for
evidence without naming the contract mismatch. This is one concrete correctness
improvement in a low-count case. For the other six unique cases, both arms chose
the expected disposition. The calibration skill added a useful estimand caveat
on separate medians, but the supplied facts do not establish a paired accuracy
advantage there. The dependency skill added detail without changing the correct
disposition. Repeating DET-01 under parallel dispatch preserved both arms'
respective outcomes.

**Promotion decision: keep all three candidates `unpromoted`.** The sample is
too small to establish repeatable task-class benefit, despite the single
determinism improvement. No critical false pass or correctness regression was
observed. This follows the policy's small-sample rule; it is not a rejection of
the skills. A follow-on evaluation needs more independently written variants per
task class, a second matched serial/parallel case for each class, recorded
response-size and reviewer-intervention measures, model build identity where
available, and D1.5 technical oracle isolation before any hidden-evaluation
claim. Untrusted-instruction scoring needs an unambiguous task contract.
