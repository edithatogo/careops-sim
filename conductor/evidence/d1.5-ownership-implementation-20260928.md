Status: locally integrated after coordinator acceptance and independent review.

## Reservation behavior

Added two tests to `tests/test_tasks.py`. One proves an active descendant path
blocks a broader task reservation; the other proves an active ancestor blocks a
nested task reservation. Both assert that unrelated work remains selectable.
These tests prove the planner's behavior when the single coordinator supplies
the live reservation list. They do not prove atomic lock acquisition or protect
against independent concurrent coordinators. The existing protocol remains
single-coordinator/manual; a distributed lease is outside this phase.

## Evaluation boundary decision

The independent contract review found that the original leaf oracle (“held-out
oracle inaccessible to worker”) could not be proven in this shared-host
environment. The recipe and packet were revised before dispatch to require the
honest outcome: document that isolation is unavailable and keep hidden
evaluation off. No oracle answers or private evaluation material were given to
the worker. This is not evidence that a hidden oracle is technically
inaccessible.

Before any untrusted or held-out evaluation is run, the D2 local CI/security
fixture should include a negative file-access probe for coordinator-held oracle
material, alongside its existing untrusted-PR secret checks. If a supported
execution boundary cannot make that probe fail closed, hidden evaluation stays
disabled. D2 remains gated by D1 and is not pulled into this leaf.
