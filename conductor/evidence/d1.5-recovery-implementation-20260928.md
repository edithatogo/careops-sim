# D1.5 recovery implementation and acceptance

Status: locally integrated after independent implementation review and
coordinator acceptance. The implementation is a read-only supervised recovery
decision helper; it does not execute retries, write ledgers, or claim process
death, exactly-once side effects, or a multi-coordinator lease.

## Delivered behavior

- Revalidates the prepared packet, source and input hashes, repository
  containment, prerequisite artifacts, and packet/ledger/checkpoint identity.
- Requires the persisted run-ledger `state` field. `integrated` and
  `ready_for_review` route to terminal/acceptance decisions before checkpoint
  interpretation; an unknown in-progress step remains a manual reconciliation
  blocker.
- Enforces checkpoint schema version, ledger/packet base commit equality,
  ordered accepted prefixes, exact artifact hashes, reservations, and resolved
  alias protections.
- Rejects input/source path symlink escapes before invoking the existing packet
  validator, returning `rebind_required` rather than following external files.
- Requires bound stop and issue-resolution attestations for eligible retries;
  sanitizes reported decision metadata and leaves prior attempt artifacts
  untouched.
