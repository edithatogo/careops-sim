# D2.3 CI trust and scheduling acceptance — 2026-10-03

Bound packet validated. All jobs have 5–20 minute timeouts. Untrusted PRs use
contents:read only, no secret references, no privileged triggers, and checkouts
never persist credentials. PR updates cancel superseded runs; main runs retain
independent evidence. Aggregate rejects missing/skipped/failed lanes on changed
inputs. No shared caches are enabled for this small E0 baseline: no untrusted
cache can be restored into publishing/release jobs. Future cache adoption needs
platform/toolchain/lockfile keys and distinct trusted namespaces.

Unit/integration selection excludes doctests; the separate documentation lane
executes them once. Native commands use --locked. Workflow regression tests
include positive budgets, <=20 minute limits and cache/trigger restrictions.
`python3 -m unittest discover -s tests -p test_ci_workflow.py -v` passes 12 tests;
`actionlint .github/workflows/ci.yml` passes. Hosted platform evidence follows.
