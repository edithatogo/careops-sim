## 4. Negative Failure Drills Ledger

To ensure fail-closed security and operational reliability, 11 distinct failure drills were simulated and verified during Phase D4:

1. **`DirtyReleaseInputError`**: Uncommitted changes injected into working tree during release packaging. Verified immediate abort without generating artifacts.
2. **`MissingArtifactError`**: Omission of expected archive (`careops-ed-0.1.0.tar.gz`) from release distribution directory. Verified consumer verifier fails closed.
3. **`DigestMismatchError`**: Bit-flip substitution in distribution archive. Verified immediate rejection with SHA-256 digest mismatch.
4. **`ExpiredEvidenceError`**: Attestation generation timestamp shifted to 31 days in past. Verified consumer verifier rejects stale evidence exceeding the 30-day horizon.
5. **`WrongCommitError`**: Attestation referencing unauthorized git commit hash (`deadbeef...`). Verified immediate abort.
6. **`IncompatibleSchemaError`**: Incompatible SPDX or SLSA schema version declared (`SPDX-1.0`). Verified fail-closed parser rejection.
7. **`ImmutableReleaseViolationError`**: Attempted in-place overwrite of existing release tag/directory. Verified security halt.
8. **`AutonomousPublicationError`**: Attempted execution of `cargo publish` or `gh release create` without `CAREOPS_HUMAN_MAINTAINER_AUTHORITY=1`. Verified hard execution stop.
9. **`SubmodulePinDivergenceError`**: Injected divergent commit into `libs/kairos`. Verified [`tools/check_kairos_pin.py`](../../tools/check_kairos_pin.py) fails with exit code 1 and restores to last-known-good commit `44261eb5cf8275f132f63a3396903d116d701dbe`.
10. **`StateConservationViolationError`**: Checkpoint corrupted such that $\text{completed} + \text{pending} \ne \text{total}$ or overlapping indices exist. Verified immediate rejection by [`tools/checkpoint_migration.py`](../../tools/checkpoint_migration.py).
11. **`PlatformReproducibilityError`**: Simulated cross-platform floating-point drift exceeding $1.0 \times 10^{-12}$ or integer event discrepancy. Verified fail-closed rejection.
