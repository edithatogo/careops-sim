# E0.1 one-patient trace — leaf acceptance (2026-10-02)

## Decision and scope

Accept `E0.1.patient.one_patient_trace` as a hand-computable synthetic contract
fixture. Its one explicit arrival, fixed triage/assessment/treatment inputs,
half-open stage intervals, discharge, work/LOS totals, patient conservation and
resource occupancy are independently recomputed by focused tests. The run seed
is recorded as a fixed run identity; no random draw or distribution is asserted.
All values are synthetic test-only values and not ED defaults or recommendations.
No simulation was implemented or run. E0.2 must bind this oracle to the Rust
schema/API and execute the native one-patient example.
