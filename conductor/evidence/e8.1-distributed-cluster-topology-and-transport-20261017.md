## 2. Distributed Cluster Topology & Multi-Node Mapping

The 4 Logical Processes of the ED simulation are mapped across distributed compute nodes:
- **`NodeId(0)`**:
  - Endpoint: `tcp://10.0.0.1:9001`
  - Hosted LPs: `LP_TRIAGE` (0), `LP_RESUS` (2)
  - Resources Owned: Triage desks, triage staff, resuscitation bays, trauma clinicians
- **`NodeId(1)`**:
  - Endpoint: `tcp://10.0.0.2:9001`
  - Hosted LPs: `LP_ACUTE` (1), `LP_BOARDING` (3)
  - Resources Owned: Acute care bays, acute staff, inpatient boarding beds, boarding staff

Zero cross-node shared mutable memory. All inter-node communication utilizes serialized network transport packets.

## 3. Transport Envelopes & Network Wire Format (`careops_ed.dist.v1`)

All network communication complies with the formal `careops_ed.dist.v1` protocol schema:
- **`DistPacket`**:
  - `schema_version`: String (`"careops_ed.dist.v1"`).
  - `packet_id`: Unique 64-bit identifier.
  - `seq`: Monotonically increasing sequence number per node pair.
  - `source_node`: Originating node identifier (`NodeId`).
  - `dest_node`: Destination node identifier (`NodeId`).
  - `payload`: Polymorphic payload (`Heartbeat`, `EventBatch`, `NullMessage`, `GvtCut`, `ResyncRequest`, `ResyncSnapshot`).
  - `timestamp_utc`: Unix epoch timestamp.

## 4. Heartbeat Protocol & Failure Detection

Nodes maintain cluster membership through periodic heartbeats:
- Heartbeat packet includes sender's sequence number, cluster epoch, and load metric.
- State transitions:
  - $\Delta t < 100\text{ ticks}$: `NodeStatus::Active`
  - $100 \le \Delta t < 300\text{ ticks}$: `NodeStatus::Suspect`
  - $\Delta t \ge 300\text{ ticks}$: `NodeStatus::Dead`
- When a node is declared dead, the cluster initiates failover and halts cross-node messaging to the failed node.

---

## 5. Packet Sequencing, Gap Detection & State Resynchronization

Network transit channels are asynchronous and unreliable. To guarantee causality:
1. Receivers track `expected_seq`.
2. Out-of-order packets where $\text{seq} > \text{expected\_seq}$ indicate dropped packets.
3. The receiver halts local event consumption and dispatches a `ResyncRequest` specifying `expected_seq`.
4. The sending node responds with a `ResyncSnapshot` containing state digests and replays missing events.
5. Once reconciled, the receiver restores normal execution.

---

## 6. Network Partition Tolerance & Quorum Protection

In the event of network partition (netsplit):
- Cluster evaluates active membership: `has_quorum = active_nodes > total_nodes / 2`.
- If quorum is lost, the minority partition immediately suspends simulation advancement to prevent divergent split-brain states.
