# P0.2 structured candidate walkthrough

**Scope:** one synthetic generic ED patient and one staff task, using the 101-row
structured candidate. This checks input IDs and interface boundaries; it is not
a runtime simulation, evidence fit or clinical validation.

1. `ed.experimentcontrols.seedstreams` maps to one `experiment.run_seed` u64,
   matching the pinned Kairos CLI scenario and seed manifest `base_seed: u64`.
   `ed.experimentcontrols.horizon` bounds the run. Arrivals use one rate process
   or explicit relative occurrence schedule under `ed.demandcasemix.arrivals`.
   Each arrival receives initial scale-versioned acuity from
   `ed.demandcasemix.acuitymix`; `arrivalmode` is conditional on a pathway that
   branches on mode.
2. `ed.spatialabm.locations` supplies stable named zone/location IDs even in
   Macro mode. `ed.resources.staffroles`, `staffcounts`, `rosters`,
   `ed.abmstaffbehavior.zoneskilleligibility` and `taskchoice` bind an available
   eligible staff slot to triage/assessment/treatment tasks. `ed.resources.beds`,
   `rooms`, `equipment` and the capacity/location schema bind allocatable
   resources. Unknown capacity cannot become zero or a free resource. The E0
   profile must identify which task classes are required, including those with
   no resource class; the static validator alone does not establish this.
3. `ed.despathways.triage`, `assessment`, `diagnostics` and `treatment` declare
   process steps. `ed.durations.intrinsicwork` is active work only; queue wait
   and local movement are generated separately. `ed.durations.transit` permits
   a declared Macro aggregate interval, while Micro travel derives from an
   optional versioned graph, graph-edge metres and speed. A profile cannot
   add both for the same movement. External transport is a different boundary.
4. Discharge uses `ed.despathways.discharge`. Admission uses
   `ed.despathways.admission` and finite destination-compatible offers from
   `ed.hospitalinterfaces.inpatientbedavailability`. ED-generated admission
   requests occur once at disposition. `ed.hospitalinterfaces.admissiondemand`
   denotes optional **external competing demand**, not another ED patient
   stream. `ed.durations.boarding` is an observed elapsed boundary target from
   provisional boarding to actual ED departure unless a separately identified
   residual delay is modeled. The ED space stays occupied through bed offer.
   `ed.durations.disposition` is absent unless a route names distinct active
   disposition work and its endpoints.
5. On physical departure, `ed.durations.cleaning` and
   `ed.resources.cleaningcapacity` govern readiness before reuse. A staff
   interruption uses `ed.despathways.preemption` and
   `ed.abmstaffbehavior.interruptionresumption` with the reviewed Q lifecycle;
   task ancestry and elapsed/remaining work survive the transition. Time
   fields carry their own source units as `time_fields.source_unit` metadata;
   ADR-0004 defines exact conversion to checked nanosecond ticks. No global
   time-unit switch is exposed.

**Coverage result:** every consumed synthetic input above has an ID in the
structured candidate. Conditional rows are absent when their pathway/mode is
disabled; all 11 deferred rows are excluded. E0 must still implement and test
profile membership, runtime timing, finite offers, queue behavior, event/metric
anchors and repeat-seed execution. These are implementation gates rather than
claims that the interface has already run.
