## Claim review

The source code and guide support a configurable pipeline that reads DXF-derived geometries, polygonises configured room-boundary linework, filters room-label points, applies explicit split/add/merge corrections, optionally normalises shared walls, and attaches projected door-line geometry. The YAML converter emits room names, wall segments and door segments. The package README describes wall and door centrelines; the guide describes zero-thickness line geometry. Example configuration names `ROOM_BOUNDARIES`, `ROOM_LABELS`, and `Internal doors`; these are example layer names only. The guide states that the representation is a local Cartesian floorplan without a CRS. The bounded sources do not establish coordinate units, metric scale, georeferencing, or a transformation. No GeoJSON output path is documented in these files.

The record correctly treats this as a software method. It does not provide an ED CAD file or validate as-operated bays, bed capacity, accessibility, clinical function, or door traversability. The test DXF is an example fixture, not an ED source. No geometry extraction or route graph was produced.
