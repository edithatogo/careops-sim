# P5.3 coverage, evidence and uncertainty report (lean)

## Scope
Generic ED model input validation after P5.1/P5.2. This is a lean Stage A
report; it blocks validated-profile claims for unsupported assumptions while
allowing explicitly experimental generic scenarios.

## Results
- P5.1: 100 registered IDs aligned with usage matrix via
  `tools/validate_p5_consumer_coverage.py`.
- P5.2: 6 executable E0 scenario/profile fixtures run and repeat identically via
  `tools/run_p52_example_smoke.py`.
- Profile packs remain data-only and are validated by Python schema/semantics
  tools; no Rust-side profile loader or calibration runner integration exists.

## Uncertainty / backlog
- Full P4 profile-pack loading through the model and calibration runner is
  deferred until a Rust loader exists.
- Cairns local values remain unknown; generic values are synthetic/assumed only.
- Rust/API Stage B coverage checks remain deferred.
- Macro/Micro consistency, conditional-dependence preservation, and
  influential-parameter sensitivity remain broader test goals, not implemented as
  a broad suite.

## Handoff
- Generic scenarios remain explicitly experimental and are profiled by manifest.
- No validated real-hospital profile claims are made.
