# Test matrix

| Phase | Required verification | Evidence boundary |
| --- | --- | --- |
| B0 | Inventory primary perinatal evidence and source versions; distinguish measured distributions from synthetic assumptions and aggregate statistics from identifiable individual hazards. Build versioned profiles for population, routes, staffing, eligibility and timing targets; verify current applicable policy rather than hardcode earlier 30/75-minute or parity/duration examples. Write schema/provenance/units/range tests and retain missing evidence, uncertainty and unresolved correlations. Evidence intake can precede core implementation. | Retain failing controls and executed receipts; planned checks are not passes. |
| B1 | Write failing nominal/induction/protracted cases with competing progression, intervention and deterioration while waiting or in transit. Implement explicit patient and service states using qualified core contracts; define hazard updates, censoring, ties, stale-event cancellation and random draw ownership. Validate bounded trajectories and observation-only policy decisions; no claim of clinical prediction follows from synthetic conformance. | Retain failing controls and executed receipts; planned checks are not passes. |
| B2 | Test vaginal and operative birth events, multiple infants, correlated records and duplicate event rejection. Implement one-to-many relationships and pre/post-birth state mapping where modeled; record neonatal observations with provenance. Verify independent maternal/infant recovery, escalation and discharge with person/episode conservation. | Retain failing controls and executed receipts; planned checks are not passes. |
| B3 | Test capability-based room matching, reservation, cleaning, closure and equipment shortages. Implement LDR/pool/monitoring/stabilisation profiles through neutral capabilities, with staffing/opening constraints. Verify boarding holds, surge demand, occupancy and horizon censoring without premature release. | Retain failing controls and executed receipts; planned checks are not passes. |
| B4 | Test configured staffing ratios, shared-team contention, breaks, shift handover and call-in latency. Implement qualified bundle or explicitly bounded approximation with role eligibility and no double booking. Verify continuous responsibility and safe handover under absence, overtime limits and escort commitments defined by the profile. | Retain failing controls and executed receipts; planned checks are not passes. |
| B5 | Test urgency reassessment, queue displacement and refusal to interrupt unsafe active phases; targets may be breached. Implement a bounded theatre service with acceptance, procedure-start and birth/completion callbacks; transfer alone is not delivery. Measure decision-to-transfer, incision and delivery separately against versioned policy; preserve delay causes and breached targets. | Retain failing controls and executed receipts; planned checks are not passes. |
| B6 | Test ward/theatre/neonatal/retrieval transfer rejection, reservation expiry, cancellation and delayed acknowledgements. Integrate transfer lifecycle and destination models, including maternal/infant split destinations and safe fallback after departure. Verify unique ownership, person/episode conservation and origin/destination/escort resource accounting. | Retain failing controls and executed receipts; planned checks are not passes. |
| B7 | Implement batch CLI and interoperable Arrow/Parquet output using qualified routes; inspect actual files with an independent reader. Run multi-day birthing to bounded theatre to maternal/infant destinations, with multiple birth, split destinations, unavailable resources and target breaches. Verify replay, named streams, worker invariance, retry/recovery and performance budgets; supply evidence to A7 without declaring clinical validation. | Retain failing controls and executed receipts; planned checks are not passes. |

Commands are resolved against real targets at packet binding; no speculative test executable is an acceptance result.
