# Test matrix

| Phase | Required verification | Evidence boundary |
| --- | --- | --- |
| A0 | Freeze CC-01 through CC-08 from the composition design, with person/episode IDs, one virtual clock, schema versions and stream ownership; keep public APIs provisional until owner review. Design two consumers and neutral fixtures before extraction; retain the ED adapter and define the minimal careops-core crate with no clinical/site defaults. Write layered JurisdictionProfile/SiteProfile schema and loader tests, contract-negative cases and compile the smallest shared slice; bind upstream capability receipts and reserve exact paths. | Retain failing controls and executed receipts; planned checks are not passes. |
| A1 | Write failing cases for branching/loop bounds, invalid transitions, progression during waiting, stale events, ties and zero-target accounting. Implement a bounded configurable pathway adapter with independently scheduled patient progression; retain the ED compatibility path. Implement versioned classification and policy clocks with reassessment, pause semantics and separate urgency/target/priority/interruption rules; prohibit future-outcome access by decision policies. | Retain failing controls and executed receipts; planned checks are not passes. |
| A2 | Write capability, capacity conservation and calendar-boundary cases, including shared pools and daylight-saving mapping. Implement separate physical/equipped/staffed/open/reserved/occupied/cleaning states and neutral capability matching. Qualify closure, maintenance and turnover without silently evicting active work; distinguish unavailable capacity from zero demand. | Retain failing controls and executed receipts; planned checks are not passes. |
| A3 | Freeze and test bundle allocation semantics with Kairos owners: all-or-none grant versus explicit staged approximation; AllOf is not an atomic allocator. Implement the qualified mechanism or a labelled bounded composite-team fallback; test contention, partial failures, rollback, expiry, cancellation and starvation policy. Implement staff calendars, breaks, handover, escort retention and on-call latency; test no double booking and non-interruptible procedure phases. | Retain failing controls and executed receipts; planned checks are not passes. |
| A4 | Write transfer-state and conservation oracles for request/offer/reservation/departure/transit/arrival/handover plus rejection, cancellation and expiry. Implement versioned transfer envelopes with operation IDs, idempotent retries and explicit ownership/resource release; test duplicate and delayed acknowledgements. Build minimal ward/community boundary models distinguishing clinically ready from actual departure, destination availability, transport delay and boarding feedback. | Retain failing controls and executed receipts; planned checks are not passes. |
| A5 | Write identity/cardinality cases for readmission, concurrent episodes, recycled ECS handles, multiple births and operative births. Implement typed one-to-many relationships and birth/entry/exit/death accounting; mother and infant can progress, recover and transfer independently. Qualify fetal-to-post-birth mapping where modeled, split destinations and duplicate birth-message rejection without encoding maternal terminology in Kairos. | Retain failing controls and executed receipts; planned checks are not passes. |
| A6 | Migrate ED through a compatibility adapter in small reviewed slices; prove unchanged fixture byte parity and document schema migration separately. Run ED to minimal ward to community with rejected/expired offers, transport cancellation, delayed discharge and horizon censoring. Verify conservation, stable stream namespaces, unrelated-module noninterference, 1/2/4 replication workers and interruption/recovery; logical hospital boundaries do not mandate PDES partitions. | Retain failing controls and executed receipts; planned checks are not passes. |
| A7 | Join the ED composition evidence with B7 birthing/theatre/maternal-infant evidence before declaring reusable cross-service contracts qualified. Extend existing observation/calibration contracts for delayed/missing observations, exclusions, censoring, latent demand, identifiability and held-out validation. Define separate activity/resource/cost/funding/outcome/equity ledgers and versioned offline fiscal exchange; test mismatched units, periods, duplicate accounting and policy lag before optimisation. | Retain failing controls and executed receipts; planned checks are not passes. |

Commands are resolved against real targets at packet binding; no speculative test executable is an acceptance result.
