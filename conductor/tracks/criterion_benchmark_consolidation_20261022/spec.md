## Contract and outputs

Keep process-level scaling, cold-start, peak RSS, native hardware and functional acceptance harnesses where needed. Do not make this track a global prerequisite; only an actual benchmark gap requires adoption. Preserve machine-readable evidence consumed by existing governance tooling.

## Ownership

## Acceptance

Representative workloads, injected performance regression, repeatable controlled baselines, stable result metrics/receipt readers, no setup bias or unconsumed computation; measure maintenance savings and preserve existing end-to-end gates.

Version/feature/maintenance/security/licence/target and wrapper-inclusive cost qualification required. Existing-tooling reuse and new adoption are distinct; dependencies are not accomplishments.

## Release and stop conditions

No clinical/production/hosted acceptance. No-go/defer is valid; reconcile downstream registry edges explicitly if no adoption is needed. Keep semantic validation and independent tests.
