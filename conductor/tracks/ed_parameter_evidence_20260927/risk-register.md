# Risks

| Risk | Mitigation |
| --- | --- |
| Unbounded “all parameters” scope | Versioned feature taxonomy and executable consumer coverage |
| Foreign/aggregate evidence transferred inappropriately | Population/definition/period limits, explicit transfer rationale |
| Numeric bounds conflated | Separate physical, observed, scenario, uncertainty and search bounds |
| Independence assumed silently | Conditional/dependence registry and joint-sampling fixtures |
| Elapsed time counted again as work/transit | DES/ABM reconciliation and identifiability review |
| Detailed agents supported only by guesswork | Simple transparent policy, assumption label, observation backlog |
| Example mistaken for Cairns truth | Separate generic/Cairns profiles and provenance |
| Unsupported family/tail or biased censoring fit | Candidate comparison, held-out checks and declared limitations |

All mitigations require phase evidence; no clinical/site validity is claimed here.
