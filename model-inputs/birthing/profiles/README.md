# Birthing profile inputs

`qld-public-reference-2022-v1.json` is a versioned, reference-only extract of selected public aggregate counts. It is not a runnable scenario, default parameter pack, clinical rule set, or local site profile. Observed data year and current policy-source revisions are recorded independently.

Staffing, site eligibility decisions and operational timing targets remain explicitly unconfigured because the public aggregate tables do not provide site rosters and this generic track has not selected an operating facility or clinical governance scope. Keep synthetic assumptions in separately identified fixtures. Do not use aggregate rates as individual hazards or assume unreported correlations.
