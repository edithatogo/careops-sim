# P1.3 normalized DES catalogue contract

Coordinator decision at base063c61e, 2026-10-01. Population uses the existing schema-v1 proposed parameter record and accepted usage-matrix-v2. This is an evidence catalogue, not an executable profile or sampler change. Six families: demand_case_mix, des_pathways, durations, resources, patient_behavior, hospital_interfaces; every registered ID in these families appears exactly once, including explicitly deferred rows. Shared ABM/measurement/experiment inventories remain owned by subsequent tasks.

Each family JSON contains schema_version1, status proposed, family, records and annotations keyed by parameter_id. Existing record schema validates every record. Registry supplies semantic name/owner; matrix supplies consumer, unit contract, decision, profile stage, value role and open gates. Time input records use canonical seconds (`s`); other unit strings retain the exact accepted matrix unit_contract. No raw source numeric cell is converted into generative value/range/default. All current generative values remain unknown, or deferred for matrix-deferred rows; boarding is output. Structural pathway/resource rules remain unselected until reviewed synthetic profile work. No distribution object or reference_default may appear without a future parameterized source/assumption decision.

Annotations contain unit_contract, value_role, evidence_refs (repository-relative path and SHA-256), acquisition_plan, candidate_families, candidate_status, and downstream_gates. Refer only to accepted source records that explicitly cover this parameter_id. Uncovered entries state a family-specific acquisition plan. All five range slots remain explicitly unknown or deferred: medians/IQR/means, consensus estimates and aggregate counts are not physical bounds, observed min/max, scenario ranges, CIs or calibration bounds. Source summary values remain available in linked original evidence records rather than duplicated or misclassified. No empirical distribution/range is accepted.

Candidate families are non-numeric research candidates, not selections or fits. Arrival process: time-varying Poisson, overdispersed/renewal process conditional on exposure/sequence evidence. Intrinsic/setup/cleaning/handover/report-review/disposition durations: empirical ECDF, gamma and lognormal only after primitive endpoints and samples are verified. Elapsed diagnostic turnaround separately permits empirical ECDF/gamma/lognormal for whole elapsed interval in Macro mode; Micro mode decomposition must prevent double-counting queues/transit. Patience: competing-risk survival with exact/interval/right-censored endpoints, never fitted from LWBS marginals. Conditional categorical tables require choice sets/denominators. Boarding has no generative candidates. All evaluations/fit coefficients/seeded samplers await P3; numeric synthetic fixtures await P4.

Dependencies preserve source limits, population/period/site transfer and future-information constraints. Unknown independence is not an assertion of independence; no RNG sampling order or algorithm introduced. Missing evidence specifies acquisition owner, endpoint/cohort/units/denominators, source/licence/readback and fit/holdout needs. Deferred patient/spatial attributes follow matrix status.

Checks must reject duplicates/missing expected IDs, unknown-as-zero/defaults, unit mismatch, stale/missing/unsupported evidence reference, unsupported numeric promotion, misclassified output, reversed/negative/nonfinite bounds, probability values outside [0,1] or categorical sums not1, impossible staffed/open/physical capacity, and invalid distribution parameterizations. Checks are catalogue-level developer tooling; runtime shape/calendar/graph/sampler gates remain P3/P4/E0. Do not claim arbitrary clinical-policy validation or empirical applicability from structure.
